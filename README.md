## ✨ About Aventra

**Aventra** is a modern student learning platform built for students from **Class 6 to Class 12**.

It combines AI-powered learning tools, personalized progress tracking, PDF resources, quizzes, homework assistance and an interactive study dashboard into one beautiful platform.

> 🎓 **One platform. One AI teacher. Smarter learning.**

---

## 🤖 Meet Mira — Your AI Teacher

**Mira** is Aventra's AI-powered study assistant.

Students can use Mira to:

- 💬 Ask study questions
- 📚 Understand difficult topics
- ✍️ Get homework help
- 🧠 Generate quizzes
- 📄 Ask questions about PDFs
- 🎯 Get class-specific explanations
- 💡 Learn concepts step-by-step
- 🗣️ Study through an interactive AI experience

Mira adapts responses according to the student's selected class and subject.

# 📄 AI PDF Library

Aventra includes a dedicated PDF learning system.

### Features

- 📤 Upload PDFs
- 💾 Store PDFs locally
- 📖 Open PDFs
- ⬇️ Download PDFs
- 🗑️ Delete PDFs
